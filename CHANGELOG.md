# Parallel Disk Tree — полная история изменений

**Период:** 9–10 октября 2026 года.  **Последняя версия:** v1.4.10.

Здесь перечислены все **17 этапов**, включая самый первый исходный ZIP, у которого не было явно указанного номера версии. Восстановлено по исходным ZIP-билдам, переданному README и журналам тестирования. Дата — дата выпуска/обсуждения в проекте, а не дата публичного релиза GitHub.

**Важно:** обновления ниже описывают содержание исходных пакетов. Статическая проверка файлов не заменяет полноценную компиляцию Windows WPF. Некоторые ранние пакеты потребовали исправлений после проверки пользователем в Visual Studio.

## Первый ZIP (до формальной нумерации) — Первый WPF-сканер
*Дата: 2026-10-09*

- Создана исходная Visual Studio solution на C# / WPF / .NET 8 с графическим деревом папок и таблицей файлов, без консольного интерфейса.
- Динамическая общая очередь папок и четыре параллельных исполнителя; вновь обнаруженные подпапки распределяются между свободными исполнителями на всех уровнях.
- Чтение метаданных через `System.IO.Enumeration.FileSystemEnumerable<T>`/`FileSystemEntry`, суммирование логических размеров и счётчиков файлов/папок без чтения содержимого файлов.
- Остановка по запросу, просмотр размеров в байтах и GiB, переход в Проводник, сортировка/постраничный вывод и экспорт дерева CSV.
- Ограничения первого выпуска: дерево в RAM, нет предварительно известного точного размера корня и нет гарантий полного доступа к защищённым каталогам.
